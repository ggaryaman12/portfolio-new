Blue Pottery Products

Beautiful and practical blue pottery products for everyday use — motifs, patterns, and objects inspired by the Jaipur tradition.

  • Product design
  • Motifs & patterns
  • Craft
My roleDesigner
TimelinePersonal project
The problem
Blue pottery is treated as a delicate showpiece.
What I did
Motifs, patterns and a six-colour palette turned into everyday objects: jewelry box, table clocks, coffee mugs, gifting boxes.
Takeaway
Beautiful and practical can be the same thing.
Impact it created
Turned a craft normally treated as ornament into a usable product line: a set of motifs and patterns, a six-colour palette, and objects built from them — a jewellery box, camel and peacock table clocks, coffee mugs and gifting boxes.

Jaipur's blue pottery is usually sold as a delicate showpiece, something you put on a shelf and never touch. There is far more you can do with the craft, so I set out to design blue pottery for everyday use instead.
